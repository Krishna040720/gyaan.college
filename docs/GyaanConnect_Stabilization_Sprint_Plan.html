Step 2: Phased Implementation Work Orders (A → G)

Work Order A Fix Lint Exclusions & React Effect Warnings
  • Add .vite_cache and dist to .gitignore and configure .oxlintrc.json ignore patterns.
  • Update package.json lint script to "oxlint src server" as a dual-layer guard.
  • In ConceptSelectionGrid.jsx: remove synchronous setLoading(true) on effect entry; manage loading via async dispatch.
  • In ProveUnderstandingStudio.jsx: remove the 7 synchronous state resets on concept change; apply React 19 key={selectedConcept?.id} in LectureTheater.jsx to reset state cleanly without cascading re-renders.
  • Acceptance Criteria: npm run lint passes with 0 errors and 0 warnings.
Work Order B Secure AI Evaluation via Server-Side Rubric Resolution
  • Refactor handleEvaluate in server/index.js: require valid conceptId and studentAnswer (≥ 5 characters).
  • Query authoritative concept in server/curriculumDatabase.js using conceptId. Return HTTP 400/404 if missing or invalid.
  • Strict Boundary: Never read mustKnowPoints or commonMisconceptions from client payload. Inject only server-side authoritative criteria into the prompt.
  • Apply authoritative resolution and answer validation to handleFollowUp (POST /api/evaluate/followup).
  • If server API key is unconfigured or Gemini times out, return HTTP 503 with { fallbackToLocal: true }.
Work Order C Remove Client API Key Storage & Direct Gemini Requests
  • In src/services/aiVoiceService.js: completely remove callGeminiDirect() and direct browser fetch() calls.
  • Routing becomes: Browser Explains → Backend Proxy (/api/evaluate) → (fallback) Local Offline Socratic Engine.
  • In src/components/GeminiSettingsModal.jsx: remove raw key input; rebrand into a secure "AI Diagnostic & Voice Settings" modal displaying server connection status, child privacy assurance, and TTS voice settings.
  • Remove localStorage.getItem('gyan_gemini_key') and localStorage.setItem('gyan_gemini_key') across all components.
Work Order D Implement Missing Curriculum Endpoints
  • Add GET /api/curriculum/subjects in server/index.js with board and class parameter validation (1–12).
  • Add GET /api/curriculum/chapters in server/index.js with board, class, and subject parameter validation.
  • Return authentic subjects and verified chapters. For in-development topics, return accurate metadata marked status: "curation_pending" instead of generating fake unit numbers.
Work Order E Unify Board Schema & Eliminate Chapter Fabrication
  • Consolidate BOARDS into a single unified schema across frontend and backend (CBSE, ICSE, UP Board, and State Boards).
  • Ensure selecting any board in curriculumData.js properly matches without defaulting to UP Board.
  • In curriculumData.js: replace generateChaptersForSubject() procedural loops with authentic NCERT Rationalised syllabus chapter titles marked status: 'curation_pending', eliminating fake repetitive quiz questions.
Work Order F Safely Remove Orphaned Dead Code
  • Confirm zero references, delete src/components/AiVoiceRoom.jsx (584 lines), and verify npm run build succeeds cleanly.
Work Order G Vitest Automated Test Harness
  • Install vitest and add "test": "vitest run" to package.json.
  • Implement 5 automated test suites:
    1. tests/conceptGraphEngine.test.js: DAG acyclic validation, prerequisite health, SM-2 interval calculations.
    2. tests/scoring.test.js: local evaluation scoring bounds (0–100), must-know coverage, misconception penalties.
    3. tests/rubricSecurity.test.js: reject invalid concept IDs; verify server ignores client-injected rubrics.
    4. tests/curriculumEndpoints.test.js: verify /boards, /classes, /subjects, /chapters, and /concepts.
    5. tests/aiResponseValidation.test.js: test normalizeEvaluationResponse against malformed or partial JSON.
